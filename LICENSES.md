# Third-party data

WordLens ships two word lists generated by `scripts/build-wordlists.ts`.
No NYT word lists are used, directly or indirectly.

## ENABLE (enable1.txt)

Used for the valid-guess allowlist and as the base for answers.
Source copy: https://github.com/dolph/dictionary (`enable1.txt`), saved as
`scripts/data/enable1.txt`. The ENABLE word list is in the public domain.

## SCOWL (via the `wordlist-english` npm package)
